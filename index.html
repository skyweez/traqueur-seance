Colle le bloc JSON que Claude te donne en MODE SÉANCES (Output 3 f). Il peut contenir plusieurs séances d'un coup — elles seront toutes ajoutées.

Lignes de la séance courante, séparées par des tabulations, dans l'ordre exact des colonnes de plan.xlsx. Copie, puis colle sous la dernière ligne du tableau Training.

Installer sur l'écran d'accueil

Pour l'installation en vraie appli (icône, plein écran, hors-ligne complet images comprises), les fichiers doivent être servis par une adresse https (voir le README : GitHub Pages). Ouverte en local, l'appli fonctionne aussi, mais sans installation ni cache d'images.

Android (Chrome) — ton Samsung

  1. Ouvre l'adresse https de l'appli dans Chrome.
  2. Menu ⋮ en haut à droite → Installer l'application (ou Ajouter à l'écran d'accueil).
  3. Au premier lancement en ligne, les images se mettent en cache. Ensuite, tout marche hors-ligne.

iPhone (Safari)

  1. Bouton Partager → Sur l'écran d'accueil → Ajouter.

Tes saisies restent sur le téléphone. Pense à Sauvegarder tout régulièrement : c'est ta seule copie de secours si tu changes de téléphone ou vides le navigateur.
